# Лабораторная работа №3: Мониторинг в распределенных системах

**Учебное заведение:** БГУ, ФПМИ, Кафедра технологий программирования

## 📌 О проекте
Данный репозиторий содержит выполнение **Задания 1** лабораторной работы №3. 
Цель работы — изучение средств мониторинга и настройка сбора телеметрии (трассировок) для Python-приложения.

В рамках задания было разработано Flask-приложение, которое с помощью библиотек **OpenTelemetry** генерирует трассировки и отправляет их в систему сбора и визуализации **Jaeger**. Само приложение и Jaeger упакованы в Docker-контейнеры и запускаются через **Docker Compose**.

## 📂 Структура репозитория
- `task1/` — директория с исходным кодом приложения и конфигурациями для Docker:
  - `app.py` — исходный код Flask-приложения с подключенным OpenTelemetry.
  - `requirements.txt` — зависимости Python.
  - `Dockerfile` — инструкция для сборки Docker-образа приложения.
  - `docker-compose.yml` — конфигурация для одновременного запуска приложения и Jaeger.
- `docs/` — директория с отчетом:
  - `report.docx` — полный отчет по лабораторной работе (включая скриншоты и ответы на контрольные вопросы).

## 🛠 Используемые технологии
- **Python 3.12** (Flask)
- **OpenTelemetry** (SDK, Jaeger Exporter, Flask Instrumentation)
- **Docker** и **Docker Compose**
- **Jaeger** (для сбора и визуализации трассировок)
